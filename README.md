# Student-Segmentation-and-Personalized-Course-Recommendation-System-for-EduPro
EduPro – Student Segmentation & Personalized Course Recommendation
EduPro is a Machine Learning-based project that analyzes student performance and learning behavior to segment students and provide personalized course recommendations.
Features
Student performance analysis
K-Means based student segmentation
PCA visualization
Learning-level prediction
Personalized course recommendations
Interactive Streamlit dashboard
Technologies
Python
Pandas
NumPy
Scikit-learn
Streamlit
Matplotlib / Plotly
